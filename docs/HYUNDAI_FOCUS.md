# Arrival Brief - 현대자동차그룹 차량용 앱 공모전 준비

정리일: 2026-10-30. Arrival Brief는 현대자동차그룹 차량용 앱 공모전에 별도로 제출하기 위해 준비하는 독립 프로젝트다. 소개 페이지, 웹 체험, 영상, 기획·검증 문서와 소스 다운로드를 이 제품의 범위로 묶는다. 신청이나 제출을 완료한 상태는 아니다.

## 해결할 문제

건물 이름을 목적지로 입력한 뒤에도 행사 안내문의 회의실에 맞는 진입문·주차 구역을 다시 확인해야 하는 상황에 집중한다. 코엑스의 공식 시설 안내는 회의실에 따라 진입문과 주차 구역을 구분한다. 이 사실을 바탕으로, 안내문 속 세부 목적지 확인에서 출발 전 브리핑까지 이어지는 흐름을 만든다.

첫 사용자는 현재 안내 가능한 코엑스 삼성동 회의실의 행사에 처음 차량으로 방문하는 운전자다. 전시장 Hall A/B/C/D는 지원하지 않는다. 안내문 입력 또는 목록 직접 선택 → 행사 시설 확인 → 차량 전체 높이·안전 주차 확인 → 브리핑 확정 → 입력 제한 시 메모리에 남아 있는 확정 내용 유지의 순서로 사용한다. 주행 중 실제 화면 표시는 운영체제의 제한을 받으며 아직 검증되지 않았다. 기존 내비게이션을 대체하거나 실시간 주차 자리를 보장하는 서비스로 표현하지 않는다.

## 현재 구현

- 코엑스 삼성동 8개 목적지 분류 중 5개를 안내한다. 컨퍼런스룸 E·300~328호·400~403호는 공식 자료의 추천 구역이 달라 `source_conflict`로 확정·내보내기를 막는다.
- 여러 장소, 취소·변경 문맥, 층 불일치, 미지원 시설과 잘못된 직접 선택은 확인을 요청한다.
- 루프박스·적재물을 포함한 차량 전체 높이와 시설 제한 2.2m를 비교한다. 높이 초과는 차단하고 같은 높이는 현장 확인 경고를 표시한다.
- 안내문이나 선택이 바뀌면 기존 확정을 해제한다. 웹은 TXT 저장·복사, Android는 확정 브리핑 복사를 지원한다.
- 웹의 정차·주행·상태 미확인은 시뮬레이션이다. 제한 상태에서는 입력·선택·내보내기를 막는다.
- Android의 `CarUxRestrictions` 어댑터, 기본 UNKNOWN 잠금, 연결 해제·재연결과 오래된 콜백 방어를 구현했다. 플랫폼 입력 허용은 물리적인 정차 판정이 아니며, 확정에 안전한 주차 상태와 전체 높이의 사용자 확인을 모두 요구한다.
- 자동차 플랫폼에서 데모 진입을 막는다. 일반 Android에서는 별도 안내를 확인한 뒤 데모를 시작할 수 있다.
- NaviHelper 3.0.5의 목적지 이름·주소를 행사 시설과 대조하는 코드를 확정 흐름에 연결했다. 사용자 요청과 플랫폼 입력 허용 시에만 조회한다. 명시한 시설·회의실 이름과 주소 형식이 일치해야 자동 확인하고, 내비 목적지 불일치는 확정을 막는다. Vehicle·브레이크 진단 의존성과 관련 권한은 제거했다. 내비 목적지나 경로는 변경하지 않는다.
- 조회하지 않았거나 결과를 확인할 수 없으면 명시적인 수동 시설 확인이 필요하다. 이미 확인한 불일치를 수동 체크나 실패한 재시도로 지우지 않는다. 시설 대조는 조회 시점만 다루며 실제 SDK 응답은 미검증이다.
- 확정한 목적지 1건을 사용자가 명시 저장·복구·삭제할 수 있다. ID·시각·자료 버전만 보관하며 24시간이 지나면 복구하지 않는다. 원문·높이·내비 주소·확정 브리핑은 저장하지 않는다. 복구는 재확인이 필요한 초안이고 주행 중 프로세스 종료 후 확정 정보를 복원하지 않는다.

웹과 Android 엔진은 규칙 기반이다. 외부 LLM이 안내문을 이해한 결과로 표시하지 않으며 입력을 외부 서버로 보내지 않는다. 실시간 빈자리·입구 좌표·실내 길찾기·승객 하차 지점은 현재 기능에 포함하지 않는다.

## 빌드와 실행 검증

현행 Android JUnit 37개(엔진 17개·세션 10개·시설 대조 8개·최근 목적지 2개)와 웹 테스트 21개가 통과했다. 양쪽 엔진은 같은 50개 판단 사례를 시험한다. 최신 파일은 `apk/ArrivalBrief_release.apk`, 버전은 `0.3.0-prototype`(versionCode 3), 크기는 5,067,560바이트이며 apksigner v2 검증을 통과했다. Android Lint 오류·경고는 0개다. [검증 JSON](verification/release-verification.json)의 버전·해시·시험·실행 범위를 기준으로 하며 서명 개인키는 저장소에 포함하지 않았다. 이전 버전의 실행 화면을 최신 기능의 실행 증거로 사용하지 않는다.

일반 Android 9에서 0.3.0의 업그레이드 설치·첫 실행·명시적 데모·시설/높이/안전 주차 확인 후 확정·주행 예시 잠금·목적지 보관·프로세스 종료 후 초안 복구를 확인했다. 복구한 초안은 높이가 비어 있고 모든 확인이 해제되며 확정 버튼도 비활성 상태였다. 실제 NaviHelper 응답과 차량 UX 전환을 확인한 결과는 아니다. 소프트웨어 에뮬레이션 환경의 System UI 응답 지연·UIAutomator null root로 성능과 장시간 안정성은 평가하지 않았다.

Pleos 실행도 시도했으나 공식 환경 요구사항을 충족하지 못한 현재 환경에서 OS 초기화와 APK 설치가 실패했다. 앱 설치·첫 실행·서비스 응답·실제 UX 제한 전환을 확인한 결과는 아니다. GPU 부재를 단일 실패 원인으로 단정하지 않고 적합한 환경에서 재검증해야 한다. [런타임 기록](verification/android-runtime.md)에 이미지 확인과 오류 관측을 남겼다.

컴파일·서명·상태 객체 테스트와 실제 차량 연결을 구분한다. 앱은 distraction-optimized 활동으로 선언하지 않았으며, 주행 중 운영체제가 화면 전체를 막을 수 있다. 실제 표시 가능 범위도 검증 대상이다.
