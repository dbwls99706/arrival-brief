# Arrival Brief - 현대자동차그룹 차량용 앱 공모전 준비

정리일: 2026-11-02. Arrival Brief는 현대자동차그룹 차량용 앱 공모전에 별도로 제출하기 위해 준비하는 독립 프로젝트다. 소개 페이지, 웹 체험, 영상, 기획·검증 문서와 소스 다운로드를 이 제품의 범위로 묶는다. 신청이나 제출을 완료한 상태는 아니다.

현재 버전은 `1.0.0-rc1` 검증 후보다. [제품 범위](PRODUCT_SCOPE.md)와 [검증 기록](HYUNDAI_VERIFICATION.md)을 현재 상태의 기준으로 사용한다.

## 해결할 문제

건물 이름을 목적지로 입력한 뒤에도 행사 안내문의 회의실에 맞는 진입문·주차 구역을 다시 확인해야 하는 상황에 집중한다. 코엑스의 공식 시설 안내는 회의실에 따라 진입문과 주차 구역을 구분한다. 이 사실을 바탕으로, 안내문 속 세부 목적지 확인에서 출발 전 브리핑까지 이어지는 흐름을 만든다.

첫 사용자는 현재 안내 가능한 코엑스 삼성동 회의실의 행사에 처음 차량으로 방문하는 운전자다. 전시장 Hall A/B/C/D는 지원하지 않는다. 같은 기기의 안내문 공유·파일 가져오기 또는 목록 선택 → 현재 유효한 행사장·높이·안전 주차 확인 → 브리핑 확정 → 실제 주차 위치 기록 → 같은 기기 재열람 또는 Android 텍스트 QR 반출의 순서로 사용한다. 주행 중 실제 화면 표시는 운영체제의 제한을 받으며 아직 검증되지 않았다. 기존 내비게이션을 대체하거나 실시간 주차 자리를 보장하는 서비스로 표현하지 않는다.

## 현재 구현

- 코엑스 삼성동 8개 목적지 분류 중 5개를 안내한다. 컨퍼런스룸 E·300~328호·400~403호는 공식 자료의 추천 구역이 달라 `source_conflict`로 확정·내보내기를 막는다.
- 여러 장소, 취소·변경 문맥, 층 불일치, 미지원 시설과 잘못된 직접 선택은 확인을 요청한다.
- 루프박스·적재물을 포함한 차량 전체 높이와 시설 제한 2.2m를 비교한다. 높이 초과는 차단하고 같은 높이는 현장 확인 경고를 표시한다.
- 안내문이나 선택이 바뀌면 기존 확정을 해제한다. 웹은 TXT 저장·복사, Android는 확정 브리핑 복사를 지원한다.
- 웹의 정차·주행·상태 미확인은 시뮬레이션이다. 제한 상태에서는 입력·선택·내보내기를 막는다.
- Android의 `CarUxRestrictions` 어댑터, 기본 UNKNOWN 잠금, 연결 해제·재연결과 오래된 콜백 방어를 구현했다. 플랫폼 입력 허용은 물리적인 정차 판정이 아니며, 확정에 현재 유효한 실제 행사장·안전한 주차 상태·전체 높이의 사용자 확인을 각각 요구한다.
- 자동차 플랫폼에서 데모 진입을 막는다. 일반 Android에서는 별도 안내를 확인한 뒤 데모를 시작할 수 있다.
- NaviHelper 3.0.5의 목적지 이름·주소를 행사 시설과 대조하는 코드를 확정 흐름에 연결했다. 사용자 요청과 플랫폼 입력 허용 시에만 조회한다. 명시한 시설·회의실 이름과 주소 형식이 일치해야 자동 확인하고, 내비 목적지 불일치는 확정을 막는다. Vehicle·브레이크 진단 의존성과 관련 권한은 제거했다. 내비 목적지나 경로는 변경하지 않는다.
- 조회하지 않았거나 결과를 확인할 수 없으면 명시적인 수동 시설 확인이 필요하다. 이미 확인한 불일치를 수동 체크나 실패한 재시도로 지우지 않는다. 시설 대조는 조회 시점만 다루며 실제 SDK 응답은 미검증이다.
- 확정한 목적지 1건을 사용자가 명시 저장·복구·삭제할 수 있다. ID·시각·자료 버전만 보관하며 24시간이 지나면 복구하지 않는다. 원문·높이·내비 주소·확정 브리핑은 저장하지 않는다. 복구는 재확인이 필요한 초안이고 주행 중 프로세스 종료 후 확정 정보를 복원하지 않는다.

Android는 같은 기기의 text/plain 공유를 받아 명시적 가져오기까지 메모리에 보류하고 웹은 40KB 이하 .txt를 받는다. 별도 주차 문구를 공식 추천과 대조하며 미해석 주차·진입 절은 확정을 보류한다. 사용자 메모는 64자·1건·24시간이다. Android의 ‘휴대폰으로 가져가기’는 저장 메모를 텍스트 QR로 표시한다. 휴대폰 카메라로 읽고 별도 저장해야 하며 서버·URL·자동 동기화를 쓰지 않는다. 앱의 만료·삭제 규칙은 휴대폰 복사본에 적용되지 않고 실제 광학 스캔은 아직 미검증이다.

웹과 Android 엔진은 규칙 기반이다. 외부 LLM이 안내문을 이해한 결과로 표시하지 않으며 입력을 외부 서버로 보내지 않는다. 실시간 빈자리·입구 좌표·실내 길찾기·승객 하차 지점은 현재 기능에 포함하지 않는다.

## 빌드와 실행 검증

현재 release APK의 버전·크기·SHA-256·시험·서명·Lint는 [검증 JSON](verification/release-verification.json)과 [Android 빌드 기록](ANDROID_BUILD.md)을 기준으로 한다. 공통 입력 사례는 시험 개수에 중복 합산하지 않는다. [런타임 기록](verification/android-runtime.md)은 실제 release 설치·업데이트·실행과 debug instrumentation, 일반 Android와 Pleos 결과를 구분한다.

0.3·0.4·0.5의 과거 실행 기록을 현재 후보의 성공 증거로 옮겨 쓰지 않는다. 컴파일·서명·상태 객체 시험은 실제 NaviHelper 응답이나 차량 UX 전환을 입증하지 않는다. 앱은 distraction-optimized 활동으로 선언하지 않았고 운영체제가 주행 중 화면 전체를 막을 수 있다. 성능·장시간 안정성·실차 물리적 시인성은 별도의 검증 대상이다.

## 출품 준비의 경계

- [Android 빌드 기록](ANDROID_BUILD.md)과 [검증 기록](HYUNDAI_VERIFICATION.md)에 최종 파일 해시, 테스트, Lint와 실행 실패 범위를 정리했다.
- 공식 양식의 익명 심사 지침과 개인 계정이 드러나는 GitHub 저장소 전달 방법은 운영 측 확인 사항이다. 비공개 심사용 계정도 2026-10-30 확인 범위에서는 공지되지 않아 접근 확인이 남아 있다.
- 참가 신청·개인정보 동의·서명·메일 접수는 이 저장소의 소프트웨어 제작과 별개다. 개인정보가 있는 접수양식과 서명은 저장소에 넣지 않는다.
- 공모전에서 AI 개발 도구 사용을 일괄 승인받았다고 표현하지 않는다. 자료와 도구의 실제 사용 조건·권리는 각각 확인한다.
- 휴대폰의 행사 안내를 차량으로 자동 전달하지 않는다. 목록 직접 선택이나 같은 기기에서의 최근 목적지 복구로 기기 간 전달이 해결됐다고 표현하지 않는다.
- 좌표 검증과 내비 목적지 전달은 현재 완료 기능이 아니다. 검증되지 않은 SDK·API 기능을 핵심 흐름에 약속하지 않는다.

## 영상과 디자인 출처

두 웹 영상은 `1.0.0-rc1`의 실제 화면 캡처를 편집한 자료입니다. 각각 30초·1280×720이며 도착 준비·확정·주행 시뮬레이션, 공식 자료 상충과 운영 제한에 따른 보류를 보여줍니다. 웹의 차량 상태는 시뮬레이션이며 연속 녹화·실차 촬영·Pleos 서비스 응답의 증거가 아닙니다. 외부 스톡 장면을 사용하지 않았습니다.

새 Android 검증 영상 `arrival-native-validation.mp4`는 현재 후보의 일반 Android debug 자동 UI 시험에서 얻은 실제 화면 5장면을 편집한 30초 자료입니다. 확정·자료 상충·메모 복구·QR·주행 잠금을 보여줍니다. 연속 화면 녹화, Pleos 서비스 성공, 휴대폰 광학 스캔의 증거는 아닙니다. APK·캡처의 정확한 버전과 해시는 영상 metadata와 런타임 기록을 따릅니다.

앱 SVG 아이콘과 화면 코드는 독립 제작했다. 관계도는 실제 지도가 아니다. Noto Sans KR의 SIL Open Font License와 QR에 사용하는 ZXing core의 Apache 2.0 라이선스·NOTICE를 보존한다. [출처와 라이선스](../ATTRIBUTIONS.md), [현재 디자인 검토](design-review.md)를 참고한다.

## 기업 로고와 공개 자료의 구분

2026-10-29 확인한 [공모전 약관](https://appdevchallenge.auto-hmg.io/terms) 제7조 제2항은 상표·이미지 등 타인의 권리에 관해 적법한 이용 권한을 확보하도록 요구한다. 기업 CI 소개나 파일 다운로드 제공 자체를 이 앱에서의 로고 사용에 대한 포괄적 허가로 해석하지 않는다. 현재 소개 페이지에는 공식 대회명과 공식 안내 링크를 표시하고, 앱 아이콘·파비콘에는 직접 제작한 Arrival Brief 아이콘을 사용한다. 공식 시설 정보는 출처와 확인일을 밝히며, 제공 기관의 공식 앱으로 표시하지 않는다.

참고로 [현대자동차 CI 안내](https://www.hyundai.com/kr/ko/info/ci)는 로고의 형태·색상 변경을 제한하고, [현대자동차 웹사이트 법적 고지](https://www.hyundai.com/worldwide/ko/footer/contact-legal/legal)는 사이트 콘텐츠 복제의 서면 동의를 요구한다. 이는 현대자동차 웹사이트의 사용 지침이며, 현대자동차그룹 공모전에서 모든 로고·자료 사용을 승인했다는 의미는 아니다.

## 색상 적용

개방된 밝은 준비 영역, 짙은 도착 패스, 블루·그린·앰버의 의미 있는 상태 표현을 사용한다. 색만으로 상태를 전달하지 않고 제목·문구·아이콘을 함께 바꾼다. 공식 기업 CI를 재현하거나 현대자동차그룹의 승인 표시로 쓰지 않는다. 실제 디자인과 검토 근거는 [디자인 기록](design-review.md)을 따른다.
