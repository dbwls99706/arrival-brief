# Arrival Brief - 현대자동차그룹 차량용 앱 공모전 준비

정리일: 2026-10-29. Arrival Brief는 현대자동차그룹 차량용 앱 공모전에 별도로 제출하기 위해 준비하는 독립 프로젝트다. 소개 페이지, 웹 체험, 영상, 기획·검증 문서와 소스 다운로드를 이 제품의 범위로 묶는다. 신청이나 제출을 완료한 상태는 아니다.

## 해결할 문제

건물 이름을 목적지로 입력한 뒤에도 행사 안내문의 회의실에 맞는 진입문·주차 구역을 다시 확인해야 하는 상황에 집중한다. 코엑스의 공식 시설 안내는 회의실에 따라 진입문과 주차 구역을 구분한다. 이 사실을 바탕으로, 안내문 속 세부 목적지 확인에서 출발 전 브리핑까지 이어지는 흐름을 만든다.

첫 사용자는 전시·컨퍼런스 장소를 처음 방문하는 운전자다. 안내문 붙여넣기 → 세부 목적지 확인 → 차량 전체 높이 확인 → 도착 브리핑 확정 → 주행 시 확정 안내만 보기의 순서로 사용한다. 기존 내비게이션을 대체하거나 실시간 주차 자리를 보장하는 서비스로 표현하지 않는다.

## 현재 구현

- 코엑스 삼성동 회의실 8개 범위의 공식 진입문·추천 주차층·구역 안내.
- 여러 장소, 부정·변경 문맥, 층 불일치와 미지원 시설의 확인 요청.
- 차량·루프박스를 포함한 전체 높이와 2.2m 시설 제한 비교.
- 확정한 브리핑의 저장·복사와 입력 변경 시 확정 무효화.
- 웹의 정차·주행·상태 미확인 시뮬레이션. 비정차 상태의 입력·선택·내보내기 제한.
- Android Kotlin 구현과 공식 Pleos Vehicle 2.3.2·NaviHelper 3.0.5의 읽기 전용 진단 코드.

웹 엔진은 설명 가능한 규칙 기반이다. 외부 LLM이 안내문을 이해한 결과로 표시하지 않으며 입력을 외부 모델로 전송하지 않는다. Android SDK 컴파일 성공은 실제 서비스 응답, 실차 연결 또는 주행 UX 제한 통합 완료와 구분한다.

## 출품 준비의 경계

아래 내용은 2026-10-28~29의 기존 공식 자료 조사와 빌드 기록을 정리한 것이다. 이번 페이지 분리 작업으로 규정이나 플랫폼 상태를 새로 확인한 것은 아니다.

- 웹 프로토타입과 시연 영상은 사용 흐름을 설명하는 준비 자료다.
- 제공하는 debug APK는 개발용 인증서로 서명한 테스트 빌드다. 참가자 release 서명과 최종 제출용 빌드는 별도다.
- 실제 차량 상태와 `CarUxRestrictions` 연결, 좌표 검증 및 실제 NaviHelper 전달, Pleos 에뮬레이터·기기 시연 검증이 남아 있다.
- 공모전의 AI 개발 도구 사용을 일괄 승인받았다고 표현하지 않는다. 실제 제출 규정과 권리 증빙은 제출 시점에 확인해야 한다.
- 참가 신청, 서명, 개인정보 동의, 심사 계정 초대 또는 외부 제출은 수행하지 않았다.
