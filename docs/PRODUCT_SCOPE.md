# 1.0 검증 후보의 제품 범위

목표는 코엑스 행사 방문의 출발 준비와 실제 주차 위치 기록을 한 흐름으로 잇는 것이다. 버전 이름은 `1.0.0-rc1`이며 정식 완성도·실차 적합성을 선언한 버전이 아니다.

## 사용 흐름

1. 같은 Android 기기의 공유 메뉴, 웹 텍스트 파일 또는 직접 붙여넣기로 안내문을 가져온다.
2. 세부 행사장을 선택한 뒤, 그 장소가 이번에 실제 방문할 행사장인지 직접 확인한다. 행사장과 별도의 주차 문구를 구분하며, 시설·층 충돌이나 장소 변경·취소·종료 표현이 있으면 확정을 보류한다. 확인이 필요한 원문 문장도 함께 보여준다.
3. 실제 차량 전체 높이와 안전 주차를 직접 확인한다. 차량 플랫폼 입력 허용과 사람의 주차 확인은 서로 대체하지 않는다.
4. 확정한 진입문·추천 주차 구역을 한 장의 도착 패스로 본다. 운전 중에는 입력·주차 메모를 잠근다.
5. 도착 후 실제 주차한 층·구역·기둥 번호를 64자 이내로 직접 남긴다. 공식 추천 구역과 실제 주차 위치는 별도 정보다.
6. 같은 기기에서 24시간 안에 안전 확인 후 다시 읽거나 삭제한다. Android에서는 저장한 메모와 현재 입력이 같을 때 **휴대폰으로 가져가기**를 눌러 일반 텍스트 QR을 표시한다. 휴대폰에서 이를 읽고 직접 복사·저장한다. 웹은 같은 기기 안의 기록만 제공한다.

메모는 저장 후 24시간에 만료되어 다시 조회할 수 없다. 앱이 활성 상태라면 만료 감시로 표시와 기록을 정리하고, 프로세스가 종료되어 있다면 다음 조회·실행 때 정리한다. 종료 중에도 정각에 백그라운드에서 삭제한다고 주장하지 않는다.

## 수동 QR 가져가기의 경계

- QR에는 저장한 주차 메모·저장 시각(KST)·휴대폰 복사본의 자동 삭제 불가 안내만 담는다. 행사 원문·계정·좌표·URL은 추가하지 않으며 서버로 전송하지 않는다.
- Android의 차량 입력 허용과 안전 주차 확인이 모두 필요하다. 미저장 수정본·만료된 기록은 QR로 내보내지 않는다.
- 편집·삭제·만료·화면 이탈·주행·상태 미확인·닫기 때 QR 표시를 지운다. 다시 표시하려면 허용 상태와 유효 저장값을 확인해야 한다.
- 휴대폰에서 텍스트 QR을 읽고 별도로 저장하는 수동 복사다. 자동 앱 연결이나 동기화가 아니며, 앱의 24시간 만료·삭제는 휴대폰 복사본을 지우지 않는다.
- 실물 휴대폰 카메라의 광학 인식은 아직 미검증이다. QR 생성·픽셀 디코드·화면 시험과 실제 광학 인식은 별도 항목으로 보고한다.

## 제공하지 않는 것

- 휴대폰에서 차량으로 자동 전송·클라우드 동기화
- 사진/PDF OCR, 일정 서비스 자동 수집
- 실시간 빈자리·혼잡도·좌표·자동 차량 위치 추적·실내 길찾기
- 주차 위치에서 사람에게로 이어지는 보행 안내
- 미지원 시설에 대한 생성형 추측이나 검증되지 않은 진입 안내

## 검증의 의미

컴파일·단위시험·일반 Android 실행·Pleos 설치·NaviHelper 실제 응답·차량 UX 제한 전환은 각각 별도 검증 항목이다. QR 생성·픽셀 디코드·Android 표시·실물 휴대폰 카메라 인식도 별도 검증이다. 하나의 성공을 다른 항목의 성공으로 표현하지 않는다. 신규 기능과 최신 APK의 결과는 release-verification 및 런타임 기록을 따른다.

## 차별화의 한계

주차 메모 자체나 진입문 정보의 최초성을 주장하지 않는다. 차별성 가설은 안내문을 안전하게 확인하는 과정과 방문 전후 기록의 연결이다. 고객 수요·현장 시간 절감·재사용률·사업 제휴는 아직 입증되지 않았다.
