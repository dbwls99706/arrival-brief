# 1.0 검증 후보의 제품 범위

목표는 코엑스 행사 방문의 출발 준비와 실제 주차 위치 기록을 한 흐름으로 잇는 것이다. 버전 이름은 `1.0.0-rc4`이며 정식 완성도·실차 적합성을 선언한 버전이 아니다.

## 사용 흐름

1. 같은 Android 기기의 공유 메뉴, 웹 텍스트 파일 또는 직접 붙여넣기로 안내문을 가져온다. 개인정보만 제거하고 장소·일정·등록 및 변경·취소·진입·주차 제한 안내는 원문대로 남긴다.
2. 세부 행사장을 선택한 뒤, 그 장소가 이번에 실제 방문할 행사장인지 직접 확인한다. 행사장과 별도의 주차 문구를 구분하며, 시설·층 충돌이나 장소 변경·취소·종료 표현이 있으면 확정을 보류한다. 확인이 필요한 원문 문장도 함께 보여준다.
3. 실제 차량 전체 높이와 안전 주차를 직접 확인한다. 차량 플랫폼 입력 허용과 사람의 주차 확인은 서로 대체하지 않는다.
4. 확정한 진입문·추천 주차 구역을 한 장의 도착 패스로 본다. Android는 확정 후 준비 입력을 접어 도착 패스에 집중하고, 허용 상태에서 **안내 수정**을 누르면 행사장·높이·안전 주차를 다시 확인한다. 운전 중에는 입력·주차 메모를 잠근다.
5. 도착 후 실제 주차한 층·구역·기둥 번호를 64자 이내로 직접 남긴다. 공식 추천 구역과 실제 주차 위치는 별도 정보다.
6. 같은 기기에서 24시간 안에 안전 확인 후 다시 읽거나 삭제한다. Android에서는 저장한 메모와 현재 입력이 같을 때 **휴대폰으로 가져가기**를 눌러 일반 텍스트 QR을 표시한다. 휴대폰에서 이를 읽고 직접 복사·저장한다. 웹은 같은 기기 안의 기록만 제공한다.

메모는 저장 후 24시간에 만료되어 다시 조회할 수 없다. 앱이 활성 상태라면 만료 감시로 표시와 기록을 정리하고, 프로세스가 종료되어 있다면 다음 조회·실행 때 정리한다. 종료 중에도 정각에 백그라운드에서 삭제한다고 주장하지 않는다.

## 일정과 등록층을 구분하는 범위

RC3는 행사장과 함께 적힌 정형 시간표·등록 안내를 별도 원문으로 보존한다. 예를 들어 `코엑스 아셈볼룸 2층`과 `참가 등록은 1층 로비에서 진행합니다.`가 별도 문장으로 있으면 1층을 행사장 층으로 바꾸지 않는다. 정차 상태의 **일정·등록 원문 보기**와 복사한 브리핑에서 구분한 원문을 확인할 수 있다.

시간표는 `행사는 HH:mm에 시작하여 HH:mm에 종료됩니다.`라는 완전한 문장에서 유효한 시각이고 같은 날 시작이 종료보다 앞선 경우만 구분한다. 등록 안내는 `등록은 [1-4]층 로비에서 진행합니다.` 또는 `참가 등록은 [1-4]층 로비에서 진행합니다.` 형태만 구분한다. 모호하거나 서로 다른 복수 안내, 부정·변경·다른 시설·미지원 장소는 계속 보류한다. 현재 개최 여부, 날짜, 로비 위치와 실내 이동 경로를 자동 확인한 결과는 아니다.

## 수동 QR 가져가기의 경계

- QR에는 저장한 주차 메모·저장 시각(KST)·휴대폰 복사본의 자동 삭제 불가 안내만 담는다. 행사 원문·계정·좌표·URL은 추가하지 않으며 서버로 전송하지 않는다.
- 기본 QR은 화면 여유에 따라 최대 400dp로 표시한다. RC4의 **QR 크게 보기**는 같은 메모·저장 시각을 유지한 채 최대 480dp로 다시 그리며 **기본 크기**로 돌아갈 수 있다. 화면·글자 크기·픽셀 상한에 여유가 있을 때만 제공한다. 일부 판독기에 유용한 대안이며 모든 패턴·카메라의 판독 성공을 보장하지 않는다.
- Android의 차량 입력 허용과 안전 주차 확인이 모두 필요하다. 미저장 수정본·만료된 기록은 QR로 내보내지 않는다.
- 편집·삭제·만료·화면 이탈·주행·상태 미확인·닫기 때 QR 표시를 지운다. 다시 표시하려면 허용 상태와 유효 저장값을 확인해야 한다.
- 휴대폰에서 텍스트 QR을 읽고 별도로 저장하는 수동 복사다. 자동 앱 연결이나 동기화가 아니며, 앱의 24시간 만료·삭제는 휴대폰 복사본을 지우지 않는다.
- 실물 휴대폰 카메라의 광학 인식은 아직 미검증이다. QR 생성·픽셀 디코드·화면 시험과 실제 광학 인식은 별도 항목으로 보고한다.

## 제공하지 않는 것

- 휴대폰에서 차량으로 자동 전송·클라우드 동기화
- 사진/PDF OCR, 일정 서비스 자동 수집
- 실시간 빈자리·혼잡도·좌표·자동 차량 위치 추적·실내 길찾기
- 주차 위치에서 사람에게로 이어지는 보행 안내
- 미지원 시설에 대한 생성형 추측이나 검증되지 않은 진입 안내

## 검증의 의미

컴파일·단위시험·일반 Android 실행·Pleos 설치·NaviHelper 실제 응답·차량 UX 제한 전환은 각각 별도 검증 항목이다. QR 생성·픽셀 디코드·Android 표시·실물 휴대폰 카메라 인식도 별도 검증이다. 하나의 성공을 다른 항목의 성공으로 표현하지 않는다. 신규 기능과 최신 APK의 결과는 [릴리스 검증](verification/release-verification.json) 및 [런타임 기록](verification/android-runtime.md)의 버전·해시를 따른다. RC3·RC2의 시험·화면을 RC4 실행 성공으로 바꾸어 쓰지 않는다. RC4 QR 중심 UI 4개와 큰 글씨 반복 4개를 전체 19개 UI 재실행으로 표시하지 않는다. [고정 안내문 사례 검증](verification/award-scenarios.md)은 개발 중 사용한 합성 사례의 재검사이며 실제 사용자 정확도가 아니다.

## 차별화의 한계

주차 메모 자체나 진입문 정보의 최초성을 주장하지 않는다. 차별성 가설은 안내문을 안전하게 확인하는 과정과 방문 전후 기록의 연결이다. 고객 수요·현장 시간 절감·재사용률·사업 제휴는 아직 입증되지 않았다. [사업성 검증 설계](BUSINESS_VALIDATION.md)와 [운영자 안내 준비 묶음](../examples/organizer/README.md)은 후속 검증을 실행하기 위한 자료이며 실제 채택·매출의 증거가 아니다.
