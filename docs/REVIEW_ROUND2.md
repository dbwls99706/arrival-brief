# Arrival Brief 모의 심사와 수정 기록

검토 대상: 0.2.0 프로토타입에서 0.3.0-prototype으로 수정한 웹·Android·기획·제출 자료. 공식 [1차 심사 기준](https://appdevchallenge.auto-hmg.io/guide/judging-awards)의 차량특화성·창의성·기술 활용성·사업성을 기준으로 네 역할의 검토를 병렬로 수행했다. 공식 세부 배점은 공개되지 않았다. 이 문서의 1~5점은 개선 우선순위를 정하는 내부 준비도이며 공식 점수·수상 확률·시장 검증 결과가 아니다.

검토 역할은 차량 경험, 기술, 사업·창의성, 제출 품질이다. 최초 결함을 기록한 뒤 담당별로 수정하고, 차량 담당이 Android 변경을, 기술 담당이 웹 변경을 교차 검토했다. 사업 담당은 공개 근거와 기획을 다시 확인했다. 사업 문구 수정에도 참여했으므로 이 재평가는 블라인드 평가가 아니다. 인터뷰·사용자 실험은 수행하지 않았다.

별도 제출 준비도 최초 평가는 3/5였다. APK 경로, 최신 증거, 익명 전달 방식, 본인 동의·서명을 검토했다. 제출 준비도는 공식 네 항목에 더해 만든 자체 점검 범위다.

## 검증 기록

APK 버전·크기·해시, Android JUnit·웹 시험 수, Lint와 런타임 상태는 [release-verification.json](verification/release-verification.json)을 기준으로 한다. 공통 판단 사례 50개는 별도의 사용자 50명이나 실차 50회 시험이 아니다. 단위 시험에 포함된 입력 사례다.

- Android: 순수 엔진·세션·시설 대조·최근 목적지의 회귀 시험. 실제 서비스 응답과 분리한다.
- 웹: 입력 판정·확인 상태·최근 목적지와 50개 공통 사례. 차량 상태는 시뮬레이션이다.
- 영상: 0.3.0 시점 웹 화면을 사용한 33초 편집본 2개. 실제 차량·NaviHelper 콜백 촬영이 아니다.
- 일반 Android: 0.3.0 설치·첫 실행·데모 확정·주행 예시 잠금, 목적지 저장 후 프로세스 재시작·초안 복구를 확인했다. 복구 시 빈 높이·확인 해제·확정 비활성 상태를 관찰했다. 환경 지연과 UIAutomator 오류를 [런타임 기록](verification/android-runtime.md)에 남겼으며 실제 SDK·성능 검증으로 확대하지 않는다.
- Pleos: 공식 이미지 부팅·설치가 실패했다. 최신 앱의 실제 차량 SDK·권한·입력 제한은 미검증이다.

## 독립 재검토의 판단

기술 담당의 웹 교차 검토는 웹 프로토타입 준비도를 4/5로 판단했다. 발견한 확정 우회를 공통 회귀에 추가해 차단했고, 실제 차량 검증으로 확대하지 않았다. 차량 담당은 Android matcher의 재현한 높은 중요도 결함과 지원 별칭 문제의 수정을 확인했다. 별도의 새 공식 점수나 차량 전체 합격 판정을 부여하지 않았다.

제출 담당의 내부 준비도는 3/5에서 4/5로 높아졌다. APK 다운로드와 익명 패키지 검증을 통과했지만 서명·운영 확인·심사 접근과 실제 Pleos 실행은 남아 있다.

사업·기획의 내부 재평가는 **창의성 설명 3/5, 사업 기획 3/5**다. 지원 사용자와 기존 대안, 구현한 차이가 구체화됐고 가정과 사실을 구분할 수 있게 됐다. 다만 유입 경로를 실제로 확보하지 못했고 휴대폰 안내 전달, 반복 방문 수요, 운영 비용과 지불 의사는 미검증이다. 문서가 정돈됐다는 판단이며 사업성이 입증됐다는 뜻은 아니다.

## 다음 단계의 수용 조건

1. 지원 Pleos 환경에서 설치·첫 실행·권한·실제 목적지 콜백과 입력 제한 전환을 기록한다. 일반 Android 데모로 대체하지 않는다.
2. 현재 입력·저장 범위를 유지한다면 전달 기능과 주행 재시작 복원은 미구현으로 표시한다. 추가한다면 실제 기기 간 흐름과 잠금 상태를 따로 검증한다.
3. 데이터가 바뀌면 상충 판단·양쪽 엔진·영상·문서를 함께 갱신한다. 사용자 수나 효과는 실제 관측 전까지 수치 실적으로 쓰지 않는다.
4. 최종 패키지 해시·링크·익명 정보 검사를 수행하고, 본인 동의·서명·심사 계정 접근·운영 전달 방식을 완료한 뒤 제출한다.

공식 기준 확인일: 2026-10-30. 자료 발행일과 공개 근거의 해석 범위는 [USER_EVIDENCE.md](USER_EVIDENCE.md)에 기록했다.
