# 안내문 준비 과정의 고정 사례 재검증

2026-11-02. 정상 안내의 불필요한 보류를 줄이면서 기존 제한을 유지했는지 확인하는 개발 검증이다. 구현 전에 작성한 **기계 합성 안내문 10개**를 고정하고 RC2와 수정한 후보에 같은 입력을 넣었다. 실제 행사 초대장, 사용자 실험, 독립된 미관측 평가셋이 아니다. 개발 중 발견한 사례를 수정 후 다시 검사한 결과이며, 실사용 정확도·시간 절감·수상 가능성을 나타내지 않는다.

## 재현과 원본

저장소 최상위에서 Node.js로 실행한다. 통과하지 않은 기대값이 있으면 종료 코드 1을 반환한다.

```sh
node scripts/evaluate-arrival-scenarios.mjs . /tmp/arrival-scenarios.json
```

- [고정 입력·사전 기대값](../../tests/award-scenarios.json): 원문, 전체 차량 높이, 정상/제약 분류, 판정 근거.
- [검증 실행기](../../scripts/evaluate-arrival-scenarios.mjs): 장소·진입문·주차층·구역, 확정 조건, 원문 출처가 있는 내보내기를 검사한다.
- [RC2 원본 결과](award-scenarios-rc2.json): 커밋 `8ed826c0f541a2605a41fbc0e92a15e7d78cf090`의 엔진, 변경 전 실패 2건 포함.
- [수정 후보 결과](award-scenarios-rc3.json): 같은 입력을 수정한 엔진에 재실행한 결과. `sourceCommit`은 실행 당시 Git HEAD이며, `sourceWorktreeChangedFromCommit`과 `engineSha256`이 실제 시험한 작업 파일을 구분한다.

고정 입력 파일 SHA-256은 `a79c994b2eb87025e1506920af56f028d73152a5317b273068fa03511509399b`다. RC2 엔진 SHA-256은 `3eed7385f221e7098e325a40dda35180d2805cb0a24ff82a0ab74250a693b375`다. 판정 기대값을 현재 엔진에서 역으로 생성하지 않았고, 변경 전 결과를 덮어쓰지 않았다.

고정 정상 사례는 **3/5 → 5/5**, 고정 제약 사례의 보류·차단은 **5/5 → 5/5**였다. 전체 기대값 통과는 **8/10 → 10/10**이다. 안전하게 보류한 모든 입력을 성공으로 세지 않고, 정상 사례의 불필요한 보류를 실패로 남겼다. 이 작은 사례집의 비율을 일반적인 서비스 정확도로 표시해서는 안 된다.

‘준비 가능’은 검토할 브리핑 후보가 생긴 상태다. 실제 행사장이 현재 유효한지, 차량 전체 높이가 맞는지, 안전하게 주차했는지에 대한 명시적인 확인이 모두 있어야 확정한다. 시각 문자열만으로 행사가 현재 진행 중이라고 판단하지 않는다.

## 수정한 해석 범위

시간표는 `행사는 HH:mm에 시작하여 HH:mm에 종료됩니다.`라는 완전한 문장만 분리한다. 시·분이 유효하고 같은 날 시작 시각이 종료 시각보다 앞서야 한다. 역순·동일 시각, 24시 이상, 잘못된 분, 이미 종료되었다는 표현, 불완전한 예정 문장은 계속 보류한다. 날짜 해석, 현재 시각과의 비교, 일정 자동 등록은 구현하지 않았다.

등록 안내는 `참가 등록은 [1-4]층 로비에서 진행합니다.` 또는 `등록은 [1-4]층 로비에서 진행합니다.`라는 완전한 문장만 행사장 층과 구분한다. 다른 시설·회의실, 비정상 층 표기, 미해석 등록 장소와 서로 다른 복수 안내는 보류한다. 로비 위치·이동 경로를 새로 추정하지 않는다.

두 종류의 원문은 판정 결과와 내보내기에 그대로 보존한다. 원문 전체의 취소·변경·다른 시설·주차·출입 제한 검사는 유지한다. 별도 [공통 회귀 입력](../../tests/decision-cases.tsv)은 기존 387개를 보존하고 양성·음성 46개를 추가한 433개다. 고정 10사례와 공통 회귀 입력의 수를 합쳐 독립 표본 수로 표현하지 않는다.

## 공식 자료와 비교하는 방법

진입문·추천 주차·높이 제한의 기준은 [코엑스 일반차량 안내](https://business.coex.co.kr/guide/conference-room-parking-information/general-vehicle/)다. 상충 여부는 [2026-02-11 공식 공지](https://business.coex.co.kr/post-meeting-notice/%EC%95%88%EB%82%B4%EC%9E%90%EB%A3%8C-%EC%BD%94%EC%97%91%EC%8A%A4-%EC%A3%BC%EC%B0%A8%EC%9E%A5-%ED%99%94%EB%AC%BC%EC%B0%A8-%EC%A7%84%EC%9E%85-%EC%95%BD%EB%8F%84/)와 대조한다. 2026-11-02 재조회 범위에서 위 표에 사용한 공식 추천과 상충 상태가 유지됨을 확인했다. 앱의 시설 자료 확인일은 기존 데이터 버전을 유지한다.

공식 사이트만 보는 사람도 같은 정보를 확인할 수 있다. 이 검증에서 측정한 것은 앱이 정보를 잘못 조합하지 않는지와 정상 원문을 그대로 활용할 수 있는지다. 사람의 검색 횟수·탭 수·소요 시간은 측정하지 않았고, 기존 내비게이션이나 공식 안내 사용자의 실패율을 가정하지 않았다.

후속 사용자 비교를 한다면 같은 안내문·차량 조건·공식 출처 접근권을 양쪽에 제공하고 순서를 교차 배정해야 한다. 준비 완료 여부, 잘못된 확정, 보류 이유 이해, 필요한 정보 누락을 사전에 정의해 양쪽에 동일하게 채점한다. 클릭 수가 적거나 빠르다는 이유만으로 더 좋은 결과로 판정하지 않고, 앱의 불필요한 보류와 추가 확인 부담도 기록해야 한다. 아직 이 사용자 비교는 시행하지 않았다.

## 증거의 경계

이 보고서는 웹 순수 엔진과 확인 함수의 실행 결과다. Android 공통 회귀 실행, APK 설치·UI 시연, Pleos SDK 실제 응답, 물리적 차량 또는 휴대폰 카메라 검증을 대신하지 않는다. 각 환경의 결과는 해당 빌드·런타임 기록을 따로 확인한다. 고객 수요, 제휴, MAU·유지율·매출 및 실제 사고 예방 효과를 입증한 자료가 아니다.
