# RC4 최종 증거와 제출 준비 검토

검토 시각: 2026-11-02T20:29:58+09:00. 대상: `1.0.0-rc4`, versionCode 13. 비교 기준: RC3 커밋 `501e9e90a202d0b1ec133e5621450c805388c94a`.

## 범위와 결론

RC4 제품 소스·APK·실행·촬영·QR 판독 기록을 작성하지 않은 검토자가 현재 파일과 기록, 원본 화면, 공개 설명을 대조했다. 확인한 범위에서 버전 혼합이나 실행 범위를 과장하는 차단 결함을 발견하지 못했다. 점수·공식 심사·수상 전망·정식 출시 인증은 부여하지 않는다.

아래 포장 도구 세 수정은 이 검토자가 작성했으므로 **작성자 자체 검증**이며 독립 검토로 계산하지 않는다. 신청서와 스크린샷 PDF의 전 페이지 검수, 최종 ZIP 조립·압축 해제 검사, GitHub·다운로드 파일의 게시 확인은 다른 담당자의 후속 범위다.

## 실패와 오류의 보존

첫 release 촬영은 글자 크기 전환 뒤 촬영 도구의 `Launch failed` 판정으로 불완료 상태다. 원본 실행 응답이 없어 최초 원인을 확정하지 않았다. 실패 캡처에는 앱이 열려 있다. 촬영 도구의 대기·응답 기록만 보완한 **동일 APK** 재시도는 `Status: ok`와 최종 기기 해시가 확인된다. 최초 불완료·실패 화면·재시도 기록을 함께 보존했고 기록 해시도 일치한다.

수집 로그에서 지정 치명 오류·ANR 서명 두 줄을 확인했으며 모두 OS 부팅의 `com.android.systemui` ANR다. 앱 관련 서명 0건과 OS ANR 2건을 분리한 설명은 원문과 일치한다. 무결함·장시간 안정성·성능 보증으로 해석하지 않는다.

## 발견과 해소

- RC4의 명시적 미촬영 객체를 기존 코드가 무조건 `path`로 조회해 포장이 실패했다. 현재 RC4 런타임의 명시 상태와 검증된 역사 영상의 버전·참조가 모두 맞을 때만 허용하도록 수정했다. 격리 검증에서 잘못된 상태·필드 누락·다른 버전·다른 참조·녹화 파일 누락 다섯 경우를 거절했다.
- 첫 후보 Lint XML이 포장 허용 확장자에서 빠져 있어 Android 증거 XML을 포함하도록 수정했다. 현재 XML 포함을 확인했다.
- 현재 화면 폴더 바로 아래의 `ArrivalBrief-app-screenshots.pdf`와 `.zip`만 `derived_screenshot_handoff_delivered_separately`로 분리했다. 크기·SHA-256·외부 ZIP 경로를 기록하고 후속 조립의 동일 바이트 검증을 사용한다. 원본 여섯 장은 필수 증거로 유지하며 임의 파일명·중첩 경로 누락을 허용하지 않음을 격리 검증했다.
- 처음 확인한 검토 목록의 최종 APK 해시는 RC3였다. 담당자의 갱신 후 RC4 APK와 일치함을 재확인했다. 기존 88점은 당시 RC1 평가로 유지한다.

앞의 포장 도구 세 항목은 작성자 자체 검증이다. 현재 실제 자료로 `delivery_plan` 및 QR 검증 함수를 호출해 통과했으며, 최종 압축·외부 ZIP 조립·압축 해제 검증은 이어지는 별도 단계에서 수행해야 한다.

## 설명과 미검증 범위

README·검토 순서·APK 안내·제품 범위·런타임·현재 갤러리는 RC4 결과와 RC3 역사 자료를 구분한다. QR 16/16은 기록한 화면의 소프트웨어 관측이며 모든 메모·시각·카메라의 성공률이 아니다. 별도 생성 이미지 비교는 400픽셀과 480픽셀 모두 98/100이고 실패 조합이 달랐다는 한계를 유지한다.

실제 Pleos 설치·권한·NaviHelper 응답·차량 UX 제한 전환, 실차 사용, 실물 휴대폰 QR 광학 판독, 실제 이용자 효과·반복 이용·사업 성과는 미검증이다. 같은 기기의 공유 수신을 휴대폰→차량 자동 전송으로 설명하지 않는다. 이번 결론은 파일·기록 정합성과 제한된 실행 근거 검토이며 접수·외부 게시 완료를 뜻하지 않는다.
