## 점수에 포함하지 않을 항목

실제 Pleos SDK 응답 및 차량 UX 제한 전환, 휴대폰 카메라의 광학 QR 스캔, 실제 사용자 과업 결과와 재사용률은 각각 별도 근거가 필요하다. 기능 구현이나 새로운 아이콘만으로 이 항목에 점수를 부여하지 않는다. 지원 장소 수와 실제 차량 사이 안내문 전송 범위도 현재 제품 범위대로 평가한다.

평가 시점의 Pleos 최종 재시도는 진행 중이며 `latest_version_verified: false`였다. 이후 새 결과가 나와도 기존 AOSP 시험을 Pleos 시험으로 바꾸어 적을 수 없다. 실제 서비스 응답을 확보한 경우에만 후속 근거와 평가 변경을 명시한다. 신청서 최종 PDF·외부 제출 ZIP의 조립과 업로드는 부모 작업의 별도 완료 조건으로, 이 앱 검토가 해당 작업을 대신하지 않는다.
