# 행사 운영자용 안내 준비 묶음

이 자료는 코엑스 삼성동의 **지원 회의실 행사** 안내를 작성·검토하고 수정 사항을 다시 알리는 데 쓰는 초안 도구다. 제휴·공식 승인·실제 배포 사례가 아니다. 운영자가 채울 빈 양식과 기계로 만든 예시를 구분했다.

| --- | --- | --- |
| [participant-notice-template.md](participant-notice-template.md) | 참가 안내 작성 | 행사 원문과 앱 이용 안내를 포함한 문안 |
| [review-checklist.md](review-checklist.md) | 게시 직전, 원문 변경 직후 | 검토자·근거·판정·수정 이력이 있는 확인표 |
| [expansion-gates.md](expansion-gates.md) | 다음 행사 또는 새 시설 검토 | 배포 범위를 늘릴지 보류할지 결정하는 승인표 |

## 한 행사 준비 순서

1. 정확한 행사명·일시·시설·행사장·층·원문 버전과 검토 담당을 확인한다. 지원 범위를 먼저 확인한다.
2. 템플릿을 채우고, 원문에 있는 변경·취소·시설 운영·출입 제한을 빠짐없이 보존한다. 앱이 보류한다고 해당 문장을 지우지 않는다.
3. 검토표로 출처, 차량과 기기 조건, 문안과 실제 앱 반응을 대조한다. 미해결 항목이 있으면 공식 원문 안내를 유지하고 앱 확정을 권하지 않는다.
4. 배포 권한이 있는 기존 참가 안내 채널에 게시할 최종 버전과 수정 공지 방법을 정한다. 이 저장소 자체가 참가자에게 전달되는 채널을 확보한 것은 아니다.
5. 장소·일정·운영 조건 변경을 알게 되면 기존 버전을 회수·표시하고 같은 채널로 수정 내용을 전달한다. 수신자가 저장한 복사본은 자동으로 갱신되지 않는다.

아셈볼룸 지원을 같은 층의 모든 번호 회의실 지원으로 확대하지 않는다. Hall A/B/C/D·다른 시설·불명확한 호실은 현재 범위 밖이다. 행사장은 주차층과 구분하며, 안내 가능 장소도 일정 변경·부정확한 층·출입 제한이 있으면 보류될 수 있다. 정적인 추천 구역은 주차 공간·진입 가능 여부의 실시간 확인이 아니다.

자료 근거는 [코엑스 일반차량 안내](https://business.coex.co.kr/guide/conference-room-parking-information/general-vehicle/)와 [주차 공지](https://business.coex.co.kr/post-meeting-notice/%EC%95%88%EB%82%B4%EC%9E%90%EB%A3%8C-%EC%BD%94%EC%97%91%EC%8A%A4-%EC%A3%BC%EC%B0%A8%EC%9E%A5-%ED%99%94%EB%AC%BC%EC%B0%A8-%EC%A7%84%EC%9E%85-%EC%95%BD%EB%8F%84/)다. 이 묶음의 공개 페이지 대조일은 2026-11-02, 앱 데이터의 기존 확인일은 2026-10-30이다. 문서 대조만으로 앱 데이터의 확인일·보류 정책을 자동 갱신하지 않았다. 실제 행사 게시 전에는 담당자가 당시 원문과 운영 조건을 다시 확인해야 한다.

## 합성 예시 실행

저장소 루트에서 다음을 실행한다.

```sh
node scripts/check-organizer-examples.mjs
```

결과는 `docs/verification/organizer-examples-rc3.json`에 기록한다. 예시는 실제 개최 행사·운영자 문안·사용자 관찰이 아니다. 1.65m 차량·안전 주차·행사장/높이 확인을 테스트 입력으로 명시하고, 확인 없이 확정되지 않는 조건도 검사한다. 이는 실제 운전자가 확인했다는 증거가 아니다. 웹 판단 엔진 재현이며 차량 API·실물 폰 QR·실사용 효용을 증명하지 않는다.

참여 동의와 환경 확인 후 사용할 빈 양식: [이용자·운영자 과업 검증 기록표](field-validation.md).
