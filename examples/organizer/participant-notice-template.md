# 참가 안내문 작성 템플릿

대괄호를 실제 정보로 채운 후 [검토표](review-checklist.md)를 완료한다. 미확인 내용을 추측해 채우지 않는다. 아래는 작성 틀이며 실제 행사 안내나 발송 완료 문안이 아니다.

## 참가자에게 전달할 본문

```text
[행사명] 참가 안내
안내 ID: [행사별 ID]
안내 버전: [v1.0]
확인 시각: [YYYY-MM-DD HH:mm KST]
일시: [주최 측이 확인한 날짜와 시간]
행사장: 코엑스 삼성동 [정확한 행사장 명칭] [행사장 층]
주차 안내: [공식 원문과 대조한 내용 또는 확인 중이라는 사실]
별도 안내: [변경·취소·출입 제한·등록 장소 등 실제 원문 내용이 있으면 그대로 기재]
시설 안내 원문: [공식 URL]
최신 행사 안내: [운영자가 관리하는 최신 버전 URL]
문의: [공개 가능한 행사 문의 채널]
```

빈 ‘별도 안내’ 항목은 발행 전에 정리할 수 있지만 **실제 제약·상충·변경 내용을 없애면 안 된다.** 앱이 이해하지 못하는 문장도 참가자에게 필요한 원문이면 유지한다. 복수 장소 행사는 이를 숨겨 한 장소로 바꾸지 않는다. 원문 전체가 보류되면 참가자는 최신 행사·시설 안내로 확인한다.

행사장과 주차층은 각각 한 줄로 구분한다. ‘행사장: 코엑스 삼성동 오디토리움 3층’처럼 시설 귀속이 같은 문장에 있어야 한다. 주최·후원사의 주소를 행사장 주소 대신 넣지 않는다. 일정·등록층을 명확히 적어도 앱이 해당 문법을 처리한다는 보장은 없으며 현재 버전에서 별도로 확인한다. 안내문 전달만으로 앱이 행사 개최 여부·시설 개방 여부를 확인하지 않는다.

이 양식은 **운영자가 배포할 완전한 안내문**이다. URL·문의·다양한 운영 문장이 포함된 완성본은 앱에서 보류될 수 있다. 별도의 `.txt` 8종은 지원 판정을 설명하는 최소 합성 예시이며, 완성 문안 전체를 자동 처리했다는 증거가 아니다. 앱 반응은 실제 완성 문안 그대로 검토한다.

## 앱 이용 안내를 함께 제공할 경우

아래 문안은 실제 사용 가능한 경로를 검토한 후 선택한다. `[URL]`이 남아 있거나 기기 호환성이 확인되지 않은 상태에서 참가자에게 게시하지 않는다.

**웹 체험용 문안**

> 안전하게 주차한 상태 또는 차량 밖에서 [확인한 HTTPS 웹 체험 URL]을 여세요. 안내문을 붙여넣거나 제공된 UTF-8 텍스트 파일을 가져온 뒤 행사장·차량 전체 높이·안전 상태를 직접 확인합니다. 확인이 필요한 원문이 표시되면 내용을 지우거나 다른 장소로 대신 선택해 확정하지 마세요. 웹 기록은 그 기기에 남으며 차량으로 자동 전송되지 않습니다.

**차량 앱 검증 참여용 문안 — 지원 환경·배포 승인·같은 기기 전달 경로 확인 후에만 사용**

> 사전에 확인한 [차종·플랫폼·앱 버전·설치 안내]에서만 진행합니다. 같은 기기에서 이 안내문을 텍스트 공유하거나 확인한 입력 방법으로 가져오세요. 휴대폰의 공유 메뉴만으로 차량에 전달되지 않습니다. 차량 플랫폼의 입력 허용 상태와 안전 주차 확인이 모두 필요합니다. 주행 중에는 입력하지 마세요. 현재 행사장과 차량 전체 높이를 직접 확인한 후에만 브리핑을 확정합니다.

**주차 메모 안내를 추가할 경우**

> 추천 구역과 실제 주차 위치는 다를 수 있습니다. 주차한 뒤 층·구역·기둥을 직접 기록하세요. 앱의 기록은 저장 후 24시간 유효하며, 종료 중 만료된 기록은 다음 조회·실행 때 정리합니다. Android의 텍스트 QR은 휴대폰에서 직접 읽고 별도로 저장하는 기능입니다. 실제 카메라 판독은 검증할 과업이며 모든 카메라에서의 인식을 보장하지 않습니다. 휴대폰에 만든 복사본은 앱에서 삭제하거나 만료되어도 자동 삭제되지 않습니다.

웹 안내 링크나 행사 안내 PDF 자체를 앱의 자동 연결 QR로 소개하지 않는다. 이 묶음은 원격 서버·자동 전송·참가자 추적을 추가하지 않는다.

## 변경 시 같은 채널에 전달할 문안

```text
[행사명] 안내 수정 — [새 버전 / 발행 시각]
대상 이전 안내: [이전 ID·버전·게시 위치]
달라진 내용: [이전 정보와 새 정보를 구분해 정확히 기재]
참가자가 확인할 최신 원문: [URL]
기존 안내를 저장했다면 최신 내용을 다시 확인해주세요.
Arrival Brief에 이전 내용을 입력했다면 새 안내 전체를 다시 확인하세요.
앱이 보류를 표시하면 제약 문장을 지우거나 다른 장소로 대신 확정하지 마세요.
문의: [공개 문의 채널]
```

수정 사유를 숨기고 정상 문장만 새로 만들어 배포하지 않는다. 수정 공지 수신 확인과 도달하지 못한 대상은 운영 기록에 남긴다. 앱·다운로드 파일·개별 복사본이 자동으로 갱신된다고 알리지 않는다.
